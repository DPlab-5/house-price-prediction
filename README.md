## 📋 Project Overview

This project builds an end-to-end machine learning pipeline that:
- Trains and compares 5 ML models on the Ames Housing dataset
- Deploys the best model as a REST API using Azure Functions
- Provides a clean web interface for predictions
- Containerized using Docker for consistent deployment
- Automated CI/CD pipeline using GitHub Actions
